# Game Event Tracker

Personal tracker for limited-time events, daily/weekly resets, and progress across my games.

## Files
- `index.html` – page layout
- `style.css` – look and colors
- `app.js` – all the features
- `firebase-config.js` – Firebase settings (sync is off while this is `null`)
- `firestore.rules` – security rules to paste into Firebase (each person can only see their own data)

## Updating
Edit or replace files in this GitHub repository. Cloudflare Pages republishes the site automatically within about a minute.
